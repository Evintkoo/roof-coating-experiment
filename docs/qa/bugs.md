# QA of report-snapshot.html (Chrome, playwright, own browser)

Conclusion: 22 bugs. 0 blocker, 5 major, 10 minor, 7 cosmetic. Data wiring is clean (1255 numbers checked, 0 mismatches). Live simulator scheduler is correct (newest wins under a 50-event burst, 1x and 6x CPU). No console errors, pageerrors, unhandled rejections or failed requests in any run; no external requests; offline and other-path load work. Memory: heap +0.35 MB per 300 events (bounded), nodes/listeners flat.
Evidence dir: scratchpad/qa/shots/*.png, scripts: scratchpad/qa/s/*.mjs. Every bug was reproduced at least twice (scripted run + second run/screenshot) unless marked UNCERTAIN. Theme-toggle items describe the SNAPSHOT (older toggle than src/web/design/theme.ts).

Cause: src/web/design/css.ts:200 (.tv-skip z-index:1, same as rail). CONFIRMED.

CONFIRMED.

Also at 768 it overlays "Budget"/"Explore all 96". CONFIRMED.

M5 Budget slider cannot select the dearest recipe. Repro: Budget panel, focus slider, press End (or drag past the right end). Chrome reports range.value "0.925438596491228", 4e-16 below c_max 0.9254385964912281, so lookup returns the second-highest tier: sentence "cost 0.92 ... headroom 0.01", marker at 0.919, while the readout says 0.93. Cause: src/web/design/molecules/sliderField.ts SLIDER_SCRIPT passes the rounded range value; src/core/opt/budgetTable lookup is exact (<=). CONFIRMED (3 profiles, twice).
